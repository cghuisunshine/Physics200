# Explain questions 3 and 4

**Learner**

why cant i say well the expell and return are one events and so in the ground frame everything takes gamma

**Tutor**

**You can—that reasoning is correct for the total round-trip time.** The question asks for each leg separately to make you demonstrate the moving-mirror reasoning.

One wording correction: emission and return are **two events at the same place in the ship frame**, so the ship measures the proper time between them:
\[
\Delta\tau=\frac{L}{c}.
\]
The ground therefore measures
\[
\Delta t=\gamma\Delta\tau=\gamma\frac{L}{c}.
\]

All four beams share the same emission event and the same return event, so this applies to all four round trips. You just cannot apply that same time-dilation argument to an individual outward or return leg, whose endpoints occur at different places in the ship frame.

**Learner**

i mean all 4 legs start and return are two events. all of them take 1 sec in the ship frame. so all of them take gamma in the ground frame

**Tutor**

Yes—exactly. All four **round trips** share the same two events: emission and return.

If those events are \(1\,\text{s}\) apart in the ship frame, they are \(\gamma\,\text{s}\) apart in the ground frame. That gives the total time for all four beams directly. Your reasoning is valid.

**Learner**

but since return and start are same event for each leg

**Tutor**

Yes—**all four beams share one emission event and one return event**, so they must have the same total travel time in any given frame.

Your time-dilation argument fully determines that total: \(\gamma L/c\). Considering the legs separately is only necessary to follow the question’s explicit instruction, not to establish the result.
